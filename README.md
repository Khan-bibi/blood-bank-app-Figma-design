# Save-A-Beat – Figma Design

This repository contains the Figma design prototype for the Save-A-Beat blood donation app.

🔗 [Click here to view the Figma design](https://www.figma.com/design/jsqdsEbHMwn6KlCvz64N2E/blood-bank?node-id=0-1&t=xBzJau4eJnaLbM2j-1)

## About the Design
The app includes:
- Donor and recipient registration
- Blood donation request flow
- Find nearby donors
- Contact details and more

This design was created in Figma and focuses on intuitive UX, accessibility, and mobile-first layout.
